# 通用 AI 施工报价工具

将施工报价经验整理为可复用、可按项目配置的 AI 工作流程，连接资料核对、范围确认、费用计算、Excel 输出与人工复核。

**项目案例展示，完整工具不公开提供。** 当前案例对应 Skill **1.1.2**，适用于装修、工装及商业空间的预算测算和报价初稿。

## 业务问题

施工报价涉及范围、工程量、材料选型和费用计算。资料不完整、人员判断口径不同，容易造成反复确认、漏项、重复计价，以及后续修改难以追溯。

项目将报价前需要确认的信息、计算口径、输出要求和复核步骤整理为标准流程，让 AI 协助完成资料整理与报价制作。

## 个人贡献

项目由丁雨推进，工作覆盖需求梳理、业务规则整理、AI 工作流配置、结果复核和迭代：

- 把业务中的口头要求整理为输入字段、确认项和范围边界。
- 将工程量、材料和价格依据纳入记录，区分已确认信息与暂估内容。
- 连接资料整理、程序计算、Excel 输出和人工复核，减少过程中的信息断点。
- 结合施工人员复核反馈调整使用流程，并以程序回归检查验证规则与导出行为。

## 工作流程

```mermaid
flowchart LR
  A[项目资料] --> B[缺失信息与范围确认]
  B --> C[工程量和价格依据]
  C --> D[程序校验与计算]
  D --> E[11 表 Excel 与说明]
  E --> F[人工复核与版本归档]
```

AI 整理信息和提出待确认问题；程序执行既定计算。正式使用前，由项目人员复核数量、价格、范围及现场条件。

## 成果与示例

| 业务使用记录 | 已确认口径 |
|---|---|
| 使用范围 | 覆盖 11 个实际项目 |
| 整体报价周期 | 由约 3–7 个工作日缩短至约 1 个工作日 |
| 正式报价 | 经人工复核后使用 |

上述为业务使用记录，描述整个报价流程，不能作为 AI 单次运行时长或准确率结论。

## 适用边界

- 工程量、材料选型、现场条件和价格依据需要按项目确认。
- 缺少资料时，应继续补充或明确标注暂估。
- 不保证自动识图及实时市场价格准确，也不替代项目人员对正式报价的复核。
